# 🌏 India Climate & Energy Atlas

An interactive data analysis project exploring the relationship between climate, energy, and economic development across India and five other Asian countries using authentic World Bank Indicators API data.

## 📌 Project Overview

This project analyzes historical trends in economic growth, carbon emissions, electricity access, renewable energy, and population.

## 🌍 Countries Covered

- 🇮🇳 India
- 🇧🇩 Bangladesh
- 🇨🇳 China
- 🇮🇩 Indonesia
- 🇱🇰 Sri Lanka
- 🇻🇳 Vietnam

## 📊 Indicators Analyzed

- GDP per capita
- CO₂ emissions
- Access to electricity
- Renewable energy consumption
- Population
- Electric power consumption

## 🛠️ Technologies Used

- Python
- Pandas
- Data visualization
- World Bank Indicators API
- Jupyter Notebook

## 📁 Repository Contents

- `india-climate-energy-atlas.ipynb` — Main analysis notebook
- `India_Climate_Energy_Atlas/` — Supporting project files, scripts, and documentation

## 🚀 Getting Started

1. Download or clone this repository.
2. Install the required Python packages listed in `requirements.txt`.
3. Open the Jupyter Notebook.
4. Run the notebook cells to explore the analysis.

## 🔎 Data Source

World Bank Indicators API: https://api.worldbank.org/

The project uses historical country-level indicators. Results depend on the availability and completeness of the source data.

## 📈 Research Note

Correlations and trends are exploratory. They do not, by themselves, establish causation.
